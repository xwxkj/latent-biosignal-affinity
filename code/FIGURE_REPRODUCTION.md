# Reproducing manuscript Figures 2 and 3

## Provenance

`Figure_independent_unit_deltas` and
`Figure_robustness_and_stimulus_sensitivity` are data-derived figures generated
with Python, pandas, NumPy and Matplotlib. They are not images generated by a
text-to-image or other generative image model.

The numerical inputs are produced by the independence-controlled pipeline in
`code/run_reanalysis.py`. The figure script then reads the resulting CSV files
and creates PNG, PDF and SVG outputs.

## Complete workflow

Obtain PTB-XL, WESAD and CASE from their original repositories. Raw human
biosignal data are not redistributed here. From the repository root, run:

```bash
python code/run_reanalysis.py \
  --data-dir /path/to/project/data \
  --results-dir /path/to/project/results_independence_controlled

python code/make_reanalysis_figures.py \
  --results-dir /path/to/project/results_independence_controlled \
  --output-dir ./figures_reproduced
```

The second command writes:

```text
Figure_independent_unit_deltas.png
Figure_independent_unit_deltas.pdf
Figure_independent_unit_deltas.svg
Figure_robustness_and_stimulus_sensitivity.png
Figure_robustness_and_stimulus_sensitivity.pdf
Figure_robustness_and_stimulus_sensitivity.svg
reanalysis_primary_results.csv
```

## Figure 2 inputs

`Figure_independent_unit_deltas` reads:

- `three_dataset_independence_controlled_summary.csv`
- `wesad/primary_cross_subject/independent_unit_deltas.csv`
- `case/primary_valence_arousal_quadrant/independent_unit_deltas.csv`
- `ptbxl/primary_patient_independent/independent_unit_deltas.csv`

All WESAD and CASE participant points are displayed. PTB-XL contains 7,491
independent patients, so the figure displays a fixed-seed subsample of at most
900 points for visual clarity. The PTB-XL mean, confidence interval and reported
statistics are calculated from all 7,491 patients, not from the display
subsample.

## Figure 3 inputs

`Figure_robustness_and_stimulus_sensitivity` reads:

- `wesad/sensitivity_latent_dimension_and_metric.csv`
- `ptbxl/sensitivity_latent_dimension_and_metric.csv`
- `ptbxl/sensitivity_age_sex_adjusted/summary.csv`
- `case/sensitivity_video_centered/summary.csv`
- `case/leave_one_video_out.csv`
- `three_dataset_independence_controlled_summary.csv`

## Determinism

The default random seed is `20260730`. Randomness is used only for horizontal
point jitter and the deterministic PTB-XL display subsample. It does not alter
any statistical estimate produced by the reanalysis pipeline.

## Conceptual Figure 1

Figure 1 is a conceptual overview and is not a statistical output. Figures 2
and 3 are the data-derived experimental visualizations.
